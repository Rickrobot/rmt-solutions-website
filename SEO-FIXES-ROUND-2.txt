SEO FIX ROUND 2 — applied 15 May 2026
======================================

Follow-up pass after live deployment verification of round 1.
Two issues addressed:

  1. Image sitemap entries (image:image blocks) were not appearing in
     the deployed sitemap.xml because Next.js 14.2.0 silently ignores
     the `images` field on MetadataRoute.Sitemap (that field was added
     in Next 14.3). Replaced app/sitemap.js with a hand-rolled XML
     route handler at app/sitemap.xml/route.js so the image sitemap
     extension works regardless of Next.js version.

  2. Page titles were exceeding ~60 chars on Google desktop SERPs
     because the root layout's title template appends " | RMT Solutions"
     (16 chars) to every child page. Trimmed 1 homepage default + 11
     service page titles + 13 location metaTitles so total title length
     after suffix stays inside the ~60-char SERP display window.

Result: 14 files modified, 1 added, 1 deleted. All JSX-parse-checked
with esbuild. The new sitemap route handler was smoke-tested with
node and confirmed to emit valid XML with the xmlns:image namespace
declared and 16 image:image blocks across 45 URL entries.

  app/sitemap.xml/route.js
    Custom route handler that emits sitemap.xml directly. Includes
    xmlns:image namespace declaration and emits image:image blocks
    for the homepage, top-level entry pages, and every service page
    (hero image surfaced). Returns Content-Type: application/xml
    with a 1-hour s-maxage CDN cache header.

DELETED

    cause a Next.js route conflict.
