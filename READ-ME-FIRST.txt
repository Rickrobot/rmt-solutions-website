STEP 2 — Delete these from your repo (CRITICAL)
==============================================================

If you skip this step the Vercel build will fail with
"two parallel pages that resolve to the same path."

  DELETE the entire directory:
    app/sitemap.xml/                  (and everything inside it)

  DELETE the file (if it still exists from round 1):
    app/sitemap.js

In a terminal at the root of your repo, run:

  git rm -rf app/sitemap.xml
  git rm -f  app/sitemap.js          # ignore the error if the file doesn't exist

==============================================================
WHAT EACH FILE DOES (in case you want to spot-check)
==============================================================

  next.config.js
      Added an `async rewrites()` block at the top so the
      canonical /sitemap.xml URL keeps working. The existing
      `redirects()` block (82 WordPress legacy redirects) is
      unchanged.

  app/sitemap-feed/route.js
      New custom sitemap route handler. Emits sitemap XML
      directly so we can include <image:image> blocks — the
      Next.js 14.2 framework helper silently drops the image
      field. Exposed at /sitemap.xml via the rewrite above.

  app/layout.js
      Homepage default title trimmed so SERPs don't truncate it.

  app/locations/[slug]/page.js
      All 13 city pages have shorter metaTitles now.

  app/services/*/page.js  (11 files)
      Each service page has a shorter title to stay under
      Google's ~60 character SERP truncation.
